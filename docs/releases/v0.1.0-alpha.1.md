PackPorter 首个 Alpha 预发布，提供 Windows x64 压缩包。下载 `packporter-v0.1.0-alpha.1-windows-x86_64.zip`，解压后运行 `packporter.exe`；同名 `.zip.sha256` 文件用于核对下载内容。

- 扫描启动器实例，选择旧、新整合包并预览迁移计划。
- 迁移存档、服务器列表、截图、资源包、光影与模组个人数据；按白名单合并 `options.txt`。
- 在设置中调整各级迁移开关与路径规则。
- 默认在迁移前备份即将覆盖的目标文件，执行失败时尝试补偿。

这是测试版本。自动备份只覆盖即将被覆盖的既有文件，不是完整实例备份；工具不转换跨 Minecraft 或 Mod 版本的数据格式。详细行为和使用步骤见 [README](https://github.com/Mowonhua/PackPorter/blob/v0.1.0-alpha.1/README.md)。
