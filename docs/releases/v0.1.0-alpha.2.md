PackPorter 第二个 Alpha 预发布，新增启动器联动和系统托盘。下载 `packporter-v0.1.0-alpha.2-windows-x86_64.zip`，完整解压后运行 `packporter.exe`，并将 `packporter-shim.exe` 保留在同一目录；同名 `.zip.sha256` 文件用于核对下载内容。

- 支持关联 PCL2 / HMCL 的 EXE，沿用原路径和已有快捷方式启动；关闭联动或移除入口并保存时自动还原原启动器。支持关联多个启动器，最后一个退出后 PackPorter 等待迁移和设置保存完成再关闭。（df36a1b）
- 启动器联动时静默进入系统托盘；可在设置中开启关闭窗口到托盘，并通过托盘显示窗口或退出。再次手动启动会唤回已有窗口，Windows GUI 启动时不再弹出控制台。（a1c9e86）
- 精简界面提示，调整设置页滚动区域、启动器列表和路径操作布局。（4ed3167、f4a387d）
- 发布包增加独立的 `packporter-shim.exe`，启动器组件可单独构建，无需编译 GUI。（d9008f7）

从 alpha.1 升级时完整解压新包；旧配置可继续使用，启动器联动和关闭窗口到托盘默认关闭。关联启动器后，请先解除关联再移动工具或启动器。原路径接管仅支持 EXE；JAR 启动方式及联动冲突处理见 [README](https://github.com/Mowonhua/PackPorter/blob/v0.1.0-alpha.2/README.md)。
